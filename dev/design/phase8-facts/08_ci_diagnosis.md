# CI diagnosis (Phase 8, step 1)

Every failure of the fork's CI, its cause, and its fix, read from the job annotations through the public GitHub API with `01_ci_runs.R` (the logs and artifacts need a signed-in account). The project lead did not provide the artifacts of F1; the annotation step of DEC-071 (`.github/scripts/ci-annotate.R`) made the causes readable instead. Plan cases (PHASE8_PLAN.md, step 1): (a) a defect of pprof; (b) a test that depends on its environment; (c) a fixture comparison outside its tolerance on a platform; (d) the workflow or the installation of dependencies.

## The final commit `f934a04` (2026-10-06)

Every job of `rewrite-check` passes (ten with Status OK, and the Linux R 4.4.0 job with its two notes, the installed size and the suggested packages it does not install), as do `rewrite-coverage` (96.47% of R lines, 99.10% of C++ lines), `rewrite-lint`, and `rewrite-pkgdown`. In `rewrite-reference`, the per-platform jobs match pprof 1.0.3 run there in all 364 cases on Windows and macOS and in 361 on Linux (D-53's three exact-test cases). The fixture-platform job failed the same 42 lme4-backed cases as at `88ef274` (logistic RE and CRE fits and their methods, up to 3.5e-4 relative, and one linear RE measure at 1.2e-8), with the report listing the same package versions as in the passing runs. Over the four runs of that job on Phase 8's final package state and the one before it, `6fce11f` and `5a291c6` passed and `88ef274` and `f934a04` failed; the package code is identical between `6fce11f` and `f934a04`, and so are the package versions and the platform string. The cause is not established. A hypothesis, unverified: the hosted Windows runners differ in processor, and a processor-dependent part of the computation (for example the C runtime's mathematical functions, which choose their implementation when they run) changes last bits that glmer's optimizer amplifies. The annotations now record the runner's processor (`.github/scripts/ci-annotate.R`), so the next runs can show whether the failures follow it. Locally, on the machine that produced the fixtures, all 364 cases match in every run.
