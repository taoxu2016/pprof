# validation/

Large or slow equivalence checks that do not ship with the package (the folder is in `.Rbuildignore`).

| Path | Contents |
|---|---|
| `fixtures/reference/` | The full reference fixture set: cases too large or slow for the shipped core set (the binary-example algorithm grid, default-size bootstrap tests, an 80,000-row simulation for D-24). Generated by `dev/reference/generate_fixtures.R`; never edited by hand |
| `run-reference.R` | Replays both fixture sets (core and full) against the in-repo package and writes the equivalence report |
| `equivalence-report.md` | The latest report: per-case outcome, largest absolute and relative differences (including values in attributes, such as the lme4 components of RE fits), how many long double vectors stored as signatures are bitwise identical, and the providers whose reference p-value lies within tolerance of a flag threshold (brief §3.4) |

Run from the repository root:

```sh
Rscript validation/run-reference.R
```

The core set also runs as part of `devtools::test()` (slow cases skip on CRAN). Comparisons of lme4-backed results run only when the installed lme4 and Matrix versions equal those in the fixture manifest; otherwise they are reported as skipped, so that version sensitivity is documented rather than hidden by tolerances (brief §3.1).
